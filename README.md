KOMETA — Comet Courier is a gravity-slingshot delivery game that plays offline in a desktop browser: aim with the mouse, read the dotted trajectory that real planet gravity bends, and launch pods from your home planet to the glowing station. Skimming a planet's atmosphere without crashing banks style points and raises your combo; every level deals a new seeded sky with a delivery quota, a limited pod supply and, later on, a drifting station.

## Run it

```sh
python3 -m http.server 8077 --directory game
# then open http://localhost:8077 in a desktop browser and click to start
```
